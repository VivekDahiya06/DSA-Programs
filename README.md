# DSA-Programs (Java Branch)

This repository contains implementations of essential **Data Structures** and **Algorithms** written in **Java**. It is organized by topics and is aimed at helping students and developers prepare for technical interviews, coding competitions, or strengthen their understanding of core DSA concepts using the Java programming language.

## 📁 Branch: Java

All implementations in this branch use the **Java programming language**, following clean, readable, and modular code principles.

---

## 🚀 Features

- ✅ Clean and modular Java code
- ✅ Well-commented and readable implementations
- ✅ Categorized by Data Structures and Algorithms
- ✅ Covers beginner to advanced topics
- ✅ Suitable for coding interviews and competitive programming

---

## 📚 Topics Covered

### 📦 Data Structures
- Arrays
- Strings
- Linked List (Singly, Doubly, Circular)
- Stacks (Using Array & LinkedList)
- Queues (Simple, Circular, Deque, Priority Queue)
- Hashing (HashMap, HashSet)
- Trees (Binary Tree, BST, AVL Tree)
- Graphs (Adjacency List, Matrix)
- Heaps (Min Heap, Max Heap)

- Disjoint Set (Union-Find)

### 🔁 Algorithms
- Searching (Linear Search, Binary Search)

- Bit Manipulation
- Sliding Window

- Topological Sort
