# DSA-Programs (C# Branch)

This repository contains implementations of essential **Data Structures** and **Algorithms** written in **C#**. It's designed for learners, developers, and interview candidates looking to strengthen their understanding of DSA using the C# programming language.

---

## 📁 Branch: `c-sharp` or `c#`

All code in this branch is implemented in **C# (.NET)** with clean, modular, and beginner-friendly syntax.

---

## 🚀 Features

- Clean and modular C# code
- Categorized into Data Structures & Algorithms
- Follows object-oriented principles
- Interview & exam-ready
- Suitable for beginners and professionals

---

## 📚 Topics Covered

### 📦 Data Structures
- Arrays
- Strings
- Linked Lists (Singly, Doubly)
- Stacks and Queues
- Trees (Binary Trees, BSTs)
- Graphs (Adjacency List / Matrix)
- Hash Tables (Dictionary, HashSet)
- Heaps (Min/Max)
- Tries
- Union-Find / Disjoint Set

### 🔁 Algorithms
- Sorting (Bubble, Merge, Quick, Insertion, etc.)
- Searching (Linear, Binary)
- Recursion & Backtracking
- Dynamic Programming
- Greedy Algorithms
- Graph Algorithms (DFS, BFS, Dijkstra, Kruskal)
- Bit Manipulation
- Sliding Window & Two Pointers
- Pattern Matching (KMP, Rabin-Karp)
